# TweakMaxing v2.0.1

Correção urgente da remoção de bloatware. Se você aplicou o modo Avançado ou Ultimate na v2.0.0, atualize.

```powershell
irm "https://tweakmax1ng.vercel.app" | iex
```

## Correção

- **Remover bloatware (APM-006) removia apps que você não escolheu.** A janela perguntava "o que manter?" com todas
  as caixas desmarcadas, então deixar um app desmarcado significava removê-lo. Pelo modo Ultimate ou pelo headless, a
  lista ia vazia e todos os apps do catálogo eram removidos, inclusive Bloco de Notas, Paint, Calculadora, Ferramenta
  de Captura e Dev Home. Os apps do Xbox também saíam mesmo quando você respondia que usa Game Pass.
  - Agora a caixa marcada significa **remover**: sem marcar nada, nada é removido.
  - Bloco de Notas, Paint, Calculadora, Ferramenta de Captura, Fotos, Câmera, Dev Home e os apps do Xbox nunca são
    removidos por essa etapa e nem aparecem na lista. Os apps do Xbox continuam sob a pergunta do Game Pass (APM-007).

## Se você perdeu algum app na v2.0.0

Use **Desfazer** na execução da v2.0.0 (reinstala pela Microsoft Store) ou reinstale um por um:

```powershell
winget install --id 9MSMLRH6LZF3 --source msstore   # Bloco de Notas
winget install --id 9PCFS5B6T72H --source msstore   # Paint
winget install --id 9WZDNCRFHVN5 --source msstore   # Calculadora
winget install --id 9MZ95KL8MR0L --source msstore   # Ferramenta de Captura
```

## Como verificar o download

```powershell
Invoke-WebRequest -Uri https://github.com/nikemafia044-a11y/tweakmaxing/releases/download/v2.0.1/TweakMaxing.ps1 -OutFile TweakMaxing.ps1
Invoke-WebRequest -Uri https://github.com/nikemafia044-a11y/tweakmaxing/releases/download/v2.0.1/SHA256SUMS.txt -OutFile SHA256SUMS.txt
(Get-FileHash .\TweakMaxing.ps1).Hash -eq (Get-Content .\SHA256SUMS.txt).Split(' ')[0]   # deve imprimir True
```
