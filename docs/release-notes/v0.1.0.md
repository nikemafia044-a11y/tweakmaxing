# TweakMaxing v0.1.0

Primeira release. Utilitário de otimização e manutenção do Windows 10/11, em português, com interface gráfica e um único arquivo para abrir — obra derivada do [WinUtil](https://github.com/ChrisTitusTech/winutil) (Chris Titus Tech, MIT), não afiliado.

## O que muda em relação ao WinUtil

1. **Ponto de restauração obrigatório e bloqueante** antes da primeira alteração da sessão. Se não puder ser criado e verificado, nada é alterado (pular exige digitar uma frase de confirmação).
2. **Desfazer de verdade.** Cada alteração grava o valor anterior em `state.json` *antes* de escrever, exporta `.reg` das chaves tocadas e pode ser desfeita por item, por sessão ou por execução antiga (`-Undo <runId>` / `-Undo latest`).
3. **Selo de evidência** em todo item: `MEDIDO` (efeito verificável), `TECNICO` (mecanismo plausível, ganho depende do contexto) ou `FOLCLORE` (sem sustentação — continua no catálogo, mas desmarcado e com aviso). Itens sem reversão possível levam o selo `Irreversível` e exigem confirmação digitada.
4. **Prévia antes de aplicar:** cada ação mostra chave/valor `antes → depois`, lidos ao vivo, antes de qualquer escrita.

## Abas e conteúdo do catálogo

- **Ajustes**: 114 tweaks no total — 67 portados do WinUtil, 47 da categoria "Jogos" (convertidos do catálogo do CS2Tuner) e 3 políticas de atualização do Windows.
- **Instalar**: 236 aplicativos (winget/Chocolatey).
- **Configurar**: 33 recursos, correções e painéis do Windows (DISM, rede, Windows Update, SFC/DISM, NTP, etc.).
- **Atualizações**: 34 pacotes appx e 8 provedores DNS pré-configurados.

## MicroWin

Gerador de ISO customizada do Windows (recurso avançado, sem necessidade de pendrive): parte de uma ISO oficial do Windows 11, remove os apps escolhidos e gera um `autounattend.xml` a partir de um modelo embutido no artefato. Fica na aba MicroWin, separado do restante para deixar claro que é um fluxo mais avançado.

## Limitações conhecidas nesta versão

- **Nenhuma escrita elevada foi executada ao vivo** nesta máquina de desenvolvimento durante a auditoria de release — a suíte automatizada cobre a lógica (Core/Engine/functions) sem elevação; os itens que exigem elevação real, hardware real ou muito tempo estão listados em `docs/testes-manuais.md` para rodada manual.
- **A geração real de ISO do MicroWin não foi testada de ponta a ponta** (precisa de uma ISO oficial do Windows 11 e tempo de montagem/DISM); a lógica de remoção de pacotes e o modelo de `autounattend.xml` têm testes automatizados, mas não uma build completa.
- **O hash do instalador do Chocolatey é só para auditoria.** A Chocolatey Software não publica um hash fixo esperado para `community.chocolatey.org/install.ps1`; o SHA-256 do instalador baixado fica no log (`Write-TmxLog`) para investigação posterior, não como um controle de integridade que bloqueia a instalação. O consentimento explícito na UI antes do download é o controle real.
- **O PSDrive `HKU:` é registrado por sessão** (para o único tweak de teclado que mexe em `HKU:\.Default`); isso é comportamento esperado, não um bug, mas vale saber se você inspecionar o estado da runspace.
- **Reativar o BitLocker depois de desativado por um tweak precisa de TPM disponível** (`Enable-BitLocker -TpmProtector`); em uma máquina sem TPM ou com o TPM desabilitado na BIOS/UEFI, o desfazer desse item específico falha e exige reativação manual.

## Como verificar o download

```powershell
Invoke-WebRequest -Uri https://github.com/<repo>/releases/download/v0.1.0/TweakMaxing.ps1 -OutFile TweakMaxing.ps1
Invoke-WebRequest -Uri https://github.com/<repo>/releases/download/v0.1.0/SHA256SUMS.txt -OutFile SHA256SUMS.txt
(Get-FileHash .\TweakMaxing.ps1).Hash -eq (Get-Content .\SHA256SUMS.txt).Split(' ')[0]   # deve imprimir True
```
