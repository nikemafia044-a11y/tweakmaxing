## Como usar

- Siga a **disposição, os espaçamentos, as cores e os textos** das imagens.
- As cores exatas estão na tabela de tokens do prompt (Fase 2). Se a imagem e a tabela divergirem, vale a tabela.
- Os textos marcados como `[N]`, `[TAM]` e `[ESPAÇO]` são preenchidos com dados reais em tempo de execução.
- Os dados de hardware do Painel (Ryzen 7 5700X3D, RX 7800 XT etc.) são exemplos: o app lê os valores da máquina.
- Na tela de Aplicativos, os quadrados com iniciais são a **alternativa**. O app real mostra o ícone oficial de cada app e só usa as iniciais quando o ícone não existe.
- As telas Limpeza, Restauração e Configurações não têm imagem: siga o mesmo estilo visual e a descrição do prompt.
